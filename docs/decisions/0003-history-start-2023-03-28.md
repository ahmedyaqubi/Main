# ADR-0003 — Research history starts 2023-03-28

- Status: **ACCEPTED** (owner, 2026-10-05)
- Date: 2026-10-05
- Milestone: M2
- Amends: PHASE_1_SPEC §1.3 (set by ADR-0001, OD-1)

## Context
ADR-0002 makes Databento the primary data provider. Databento's consolidated US-equities
dataset (`EQUS.MINI`, 1-minute bars and BBO) starts on **2023-03-28**. Before that date,
Databento has QQQ bars only from Nasdaq's own venue (`XNAS.ITCH`), which is not the consolidated
tape the spec requires for the reference price `P_T` (spec §3) and the selection spot `S` (§5).
Options data (`OPRA.PILLAR`) is available back to 2013, so the binding constraint is the
underlying, not the options.

Options considered (M2 cost review, 2026-10-05):
- (a) Use Nasdaq-venue bars for 2022-11-14 → 2023-03-27 → two different price definitions in one dataset.
- (b) **Start the window on 2023-03-28** → about 90 fewer sessions (~9% of the sample).
- (c) Buy one month of ThetaData stock data for the gap → a second vendor for one stretch.

## Decision
Option (b). The research window for **all** labels, features, and backtests starts on
**2023-03-28** (the first session with consolidated equity data at Databento). Config:
`history.option_era_start = "2023-03-28"`, `history.underlying_start = "2023-03-28"`.

## Consequences
- ~885 sessions instead of ~980, a little over 3.5 years through 2026-10-02. The walk-forward layout (spec §8)
  is unchanged; it yields one or two fewer test folds.
- Every session in the window has a 1DTE expiration (the daily-expiration era began 2022-11-14),
  so no day-of-week bias is introduced.
- T-TIME-08 tests the new start date.
- Extending history earlier stays a "Later" item and would need another provider for the
  underlying plus a new ADR.
